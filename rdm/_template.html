RDM: the cable talks back

RDM (Remote Device Management, ANSI E1.20) runs on the same two DMX wires. The console slips RDM packets, start code 0xCC, in between ordinary DMX packets. It addresses one fixture at a time by its 48-bit UID, then lets go of the line so that fixture can answer.

Five scenes play in a loop; use ‹ › above the controls to jump between them. The start code still rolls as single marbles. After that each glass capsule is one byte, its 8 bits shown as rings with copper caps for the start and stop bits. In scenes 4 and 5 each long tube is a whole packet.
