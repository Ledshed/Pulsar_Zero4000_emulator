DMX512 slot stream

One RS-485 line, 250,000 bits a second, six RGB fixtures. Every packet opens with a BREAK (line LOW) and a mark after break (HIGH), then a start code and one slot per channel. Each slot is 11 marbles: a start bit, 8 data bits sent lowest bit first, and 2 stop bits.

Not like WS2812: an addressable LED takes its bits off the line and blocks them, so data stops at the first LED that is not yet full. A DMX fixture takes nothing. Every slot rolls past every fixture to the end of the cable. Each fixture counts the slots going by and copies the three at its address, and the stream is never interrupted.
