All units

    Each unit is a separate Zero 4000, with its own panel settings, audio source, filters and outputs. Give each one its own sACN universe (or different addresses) so they don't fight over the same lights. New units start on the next free universe.

    2 · Level

    Aim for the IN meter peaking in the yellow. The original has no level control (it adjusts itself), so you can usually leave trim at 0 dB.

    Meters

    The round lamp under each band lights when that band triggers. The amber outline marks the band's running average (AGC), which the level has to rise above to trigger.

    Outputs

    Channel colours

    Patch: which DMX addresses each channel drives

    ChannelDimmer addressesColour fixtures (start addr.)Colour order

    Separate addresses with commas and use a dash for ranges, e.g. 1, 5, 9-12. A colour fixture uses 3 (RGB) or 4 (RGBW) addresses from its start address, in the order you pick, and shows the channel's colour. With RGBW, any white in the colour goes to the W channel.

    Quick patch: fill in a row of fixtures for me

    Fixtures are assigned in turn: Bass, Tenor, Alto, Treble, Bass, … so a chase runs along the whole row.

    For WLED, use its IP address (shown in WLED under Config → WiFi Setup, or on your router). In WLED, under Config → Sync Interfaces → Realtime, make sure Receive UDP realtime is ticked. Port 4048 is the standard DDP port; don't use WLED's web port (80).

    General

    When you untick an output, it sends black (and an sACN stream-terminate) so your lights don't freeze on the last frame.
